# AI Chatbot

This is a simple AI-powered chatbot built using Python.  
It uses basic Natural Language Processing (NLP) with pre-defined responses to interact with the user.

## How to Run

1. Clone the repo:
   ```
   git clone https://github.com/shreyas-1112/AI-Chatbot.git
   cd AI-Chatbot
   ```

2. Run the chatbot:
   ```
   python chatbot.py
   ```

Type "exit" to stop the chatbot.
